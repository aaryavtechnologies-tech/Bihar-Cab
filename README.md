# Bihar Cab — Official Website

Official website for **Bihar Cab**, a 24/7 cab and taxi service based in Patna, Bihar, India.

## Features
- **Patna Local & Outstation Taxi Services**: Real-time fare inquiry and WhatsApp booking.
- **Airport & Railway Station Transfers**: 24/7 dedicated transit hub transfers (Patna Airport, Patna Junction, Patliputra Junction, Danapur, Rajendra Nagar).
- **Verified Fleet**: Authentic vehicle photography showcasing Maruti Suzuki Dzire, Ertiga (7-seater), Mahindra Scorpio, Toyota Innova Crysta, and Hyundai Aura.
- **Special Event & Wedding Bookings**: Decorated car bookings for ceremonies, weddings, and celebrations.
- **Intercity & Regional Sightseeing**: Dedicated pilgrimage and heritage packages to Gaya, Bodh Gaya, Rajgir, Nalanda, Deoghar, and Muzaffarpur.

## Tech Stack
- HTML5 semantic structure
- Custom modern CSS3 (responsive grid, zero layout shifts, optimized media queries)
- Vanilla JavaScript (dynamic WhatsApp dispatch with pre-filled route inquiries, mobile navigation)
